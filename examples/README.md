# Examples

Everything here was generated by help2skill 0.1.0 from the CLI itself; only the
hand-written guidance in `todo/SKILL.md` was written by hand.

| Folder | CLI | What it shows |
|---|---|---|
| [`todo/`](todo) | A small Typer app ([`todo.py`](todo/todo.py)) | `--llms` output ([`llms.md`](todo/llms.md)) and a `SKILL.md` with hand-written examples that `help2skill check` keeps honest. Tested in CI. |
| [`sqlite-utils/`](sqlite-utils) | [sqlite-utils](https://github.com/simonw/sqlite-utils) 4.2.1 (Click, 48 commands) | A large CLI: `SKILL.md` keeps an index, the full reference goes to [`references/commands.md`](sqlite-utils/references/commands.md). Shared options are listed once. |
| [`pipx/`](pipx) | [pipx](https://github.com/pypa/pipx) 1.18.15 (argparse) | The Markdown reference of an argparse CLI ([`reference.md`](pipx/reference.md)). |

sqlite-utils (Apache-2.0) and pipx (MIT) belong to their authors; the files here are
generated from their help text for illustration.

The pipx help text includes the path of the Python running it. help2skill warned
about it, and it was replaced with `/path/to/python` by hand: review generated
files for machine-specific values before committing them.

Try the drift check on the todo example (from the repository root):

```console
$ uv run --with typer help2skill check todo:main examples/todo/SKILL.md --app-dir examples/todo
examples/todo/SKILL.md: in sync with todo:main
```
